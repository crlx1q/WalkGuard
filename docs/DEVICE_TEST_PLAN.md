# Проверка на Android-устройстве

Эти проверки требуют телефона и **не выполнены в текущей среде**. Успех автоматических тестов не заменяет проверку цепочки CAMERA → AI → RISK → OVERLAY на устройстве.

## Подготовка

Android 8.0+ (API 26), задняя камера; для полного набора системных ограничений проверить также Android 12, 13, 14, 15 и 16. Рекомендуется минимум один Pixel и один аппарат другого производителя. Установить APK, очистить данные, начать в помещении с контролируемыми сценами.

| Проверка | Ожидаемый результат |
|---|---|
| Первый запуск | STANDBY, CAMERA OFF, FPS отсутствует, нет использования камеры |
| Отказ камеры | Следующий шаг настройки недоступен; доступна ссылка на настройки, камера не запускается |
| Постоянный отказ | Можно открыть настройки вручную; приложение не зацикливает запросы |
| Отказ оверлея | Статус остаётся неполным; запуск отклоняется |
| Отказ уведомлений / выключенный канал | Настройка не объявляется завершённой; доступен переход в настройки уведомлений |
| Возврат из настроек | Статусы разрешений перечитываются |
| DEMO | Настоящее окно TYPE_APPLICATION_OVERLAY, метка DEMO, камера выключена; исчезает через 4,5 секунды, включая переключение в другое приложение |
| Ввод и прокрутка под дугой | Ввод, касания и жесты основного приложения продолжают работать |
| Защищённые диалоги | Оверлей скрыт системой; собственные запросы разрешений подавляют его до возврата |
| Начать прогулку | Постоянное уведомление, системный индикатор камеры; ACTIVE приходит от CameraState.OPEN |
| Контролируемый человек / стул | Настоящие detections с confidence; центральный устойчивый крупный объект вызывает предупреждение |
| Объект с края кадра | Сам по себе не запускает центральное предупреждение |
| Статичный автомобиль на записи | Сам по себе не вызывает CRITICAL |
| Пустая сцена | Уровень IDLE; нет утверждения, что путь безопасен |
| Наклон горизонтально | КАМЕРА НЕ ВИДИТ ДОРОГУ, предупреждения очищены, инференс приостановлен |
| Поворот телефона | Корректные цвета, ориентация, aspect ratio и координаты; нет аварии |
| Широкоугольная камера отсутствует | Используется обычная задняя камера; реальная информация об объективе в диагностике |
| Переключение Telegram / Chrome | Анализ продолжается в допустимом Android camera FGS; предупреждение поверх приложения, если система разрешает |
| Остановить в приложении | Камера освобождена, окно удалено, уведомление исчезает, состояние STOPPED |
| Остановить из уведомления | Тот же результат; возврат во Flutter показывает STOPPED |
| Быстрые запуск/остановка 20 раз | Нет двойной камеры, оставшегося окна, зависшего STARTING или возобновления после STOP |
| Блокировка экрана | Сервис прекращает работу; после разблокировки автоматического запуска нет |
| Телефонный звонок / другое приложение камеры | При потере камеры — явная ошибка и освобождение ресурсов; требуется новый явный запуск |
| Отзыв разрешения в Android | Камера прекращает работу; возврат отражает актуальное состояние |
| Удаление из недавних / Force stop | Нет автоматического возобновления; камера не работает скрыто |
| Ошибка модели | При сборке тестового варианта с повреждённым файлом запуск заканчивается ошибкой, камера закрыта |
| Настройки во время прогулки | Частота, чувствительность, задержка, вибрация и оверлей действительно меняются на нативной стороне |
| Предупреждения выключены | Камера остаётся активной; оверлея и вибрации нет |
| Мини-превью | Обновляется только при предупреждении, не записывается, второй поток камеры не появляется |
| Уменьшение анимации Android | Оверлей появляется/исчезает без ValueAnimator; приложение остаётся управляемым |
| Авиа-режим, Wi-Fi выключен | После установки модель загружается и выполняет инференс полностью локально |
| 30 минут ECO/BALANCED/PERFORMANCE | Записать реальные FPS, среднее/последнее время инференса, расход энергии средствами Android, thermal status; не подставлять расчётные значения |
| Нагрев | При MODERATE/SEVERE цель ограничена 3 FPS; при CRITICAL сервис останавливается |
| Проверка файлов / трафика | Нет записанных кадров и сетевых запросов приложения; модель входит в assets APK |

Для фоновых сценариев не держать тестовый экран поверх WalkGuard: переключиться в настоящие приложения и отдельно проверить камеру и уведомление. Не проверять надёжность подсказок, переходя дорогу с опущенным взглядом.

## Команды

```sh
flutter devices
flutter test integration_test/app_test.dart -d DEVICE_ID
cd android
./gradlew :app:testDebugUnitTest
```

Интеграционный smoke test только подтверждает связь Flutter с нативным состоянием и сам не выдаёт разрешения или запускает камеру. В debug-манифесте отсутствует INTERNET, поэтому сетевые Flutter VM Service/DevTools недоступны; при необходимости используйте отдельный локальный отладочный вариант. Не добавляйте INTERNET в распространяемый WalkGuard.


## Дополнительно для версии 0.2

- Обновить 0.1 поверх существующей установки через `adb install -r`: сохранить режим, чувствительность и ранее выданные разрешения.
- Пройти/пропустить приветствие; закрыть и открыть приложение — приветствие больше не появляется. Повторить его из настроек.
- Сравнить Сигнал / Контур / Сегменты через DEMO поверх другого приложения, портрет/альбом, с вырезом и без.
- Проверить минимальные и максимальные размер, толщину, отступ; текст/мини-превью не обрезаются.
- Проверить, что экран под оверлеем принимает касания; надпись DEMO всегда видна даже при выключенном тексте.
- Проверить отключение анимации в WalkGuard и системных настройках.
- Изменить оформление при активной прогулке: камера продолжает работу, предупреждение принимает новые параметры.
- Восстановить оформление: чувствительность, режим анализа, вибрация и разрешения не сбрасываются.
- Скрыть показатели главного экрана, проверить сохранение после перезапуска.
